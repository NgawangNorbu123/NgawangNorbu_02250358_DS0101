# Aim & Objectives

Master essential terminal navigation.

Create, manage, view, and search files and directories.

Learn basic system monitoring and network testing.

Understand fundamental process management.

# Theory
Linux is an open-source operating system widely used in servers, cloud computing, and development. Users interact with it primarily through a text-based Command Line Interface (CLI).

# Key concepts include:

File System: A hierarchical structure where everything is organized into directories (folders) and sub-directories starting from the root (/).

Processes: Programs currently running in the system's memory.

Permissions: Rules that control who can read, write, or execute a file.

# Procedure
1. Basic Navigation & Shortcuts
pwd: Prints the full path of your current directory.

cd Student_Lab: Moves into the "Student_Lab" folder.

cd .. / cd ../..: Moves up one or two levels in the directory tree.

cd /: Changes to the system's root directory.

cd -: Switches back to the previous directory.

ls -lh: Lists files with detailed info (permissions, dates) and human-readable sizes (KB, MB).

tree: Visually displays the directory structure as a tree diagram.

clear: Clears the terminal screen.

history: Shows a list of previously typed commands.

[TAB] key: Auto-completes file or directory names.

2. Directory Management
Create nested folders: mkdir -p Student_Lab/Linux Networking (Creates parent and sub-folders at once).

Create sub-folders: mkdir commands scripts (Creates multiple folders in the current directory).

Delete a folder: rm -r Programming (Deletes a folder and everything inside it recursively).

3. File Management & Viewing
Create an empty file: touch notes.txt

Copy files: cp notes.txt commands/ (Copies a file to a new location).

Move or rename: mv practice.txt linux_practice.txt (Renames or moves a file).

Delete a file: rm notes.txt

Check file details & type: ls -l (shows permissions/size) and file notes.txt (shows if it is text, data, etc.).

Count words: wc notes.txt (Displays total lines, words, and characters).

Write to a file: echo "Text" > file.txt (Overwrites file) or echo "Text" >> file.txt (Appends to the end of the file).

Read a file: * cat file.txt (Prints the entire file to the screen).

head file.txt (Shows the first few lines).

less file.txt (Lets you scroll through large files page-by-page).

4. Searching
Search text inside a file: grep "Linux" notes.txt (Finds and prints lines matching the word).

Search for a file: find Student_Lab -name "*.txt" (Finds all text files inside a specific directory).

5. Networking & System Info
Check internet connection: ping google.com (Tests connection stability and speed).

Download a file: wget https://example.com/sample.txt (Downloads a file from the web).

System details: uname -a (Kernel and system info) and cat /etc/os-release (OS version).

Identity & Uptime: whoami (Current username) and uptime (How long the system has been running).

6. Process Management
ps: Lists processes running in your current terminal session.

top: Displays a real-time, dynamic view of active system resources (CPU, Memory) and processes.

kill <PID>: Stops a specific running program using its Process ID (PID).
