# Introduction to Jenkins Installation and Configuration
# Aim & Objectives
To learn how to use Jenkins to automate the building, testing, and deployment of software using a CI/CD framework.

Understand Jenkins and the concept of CI/CD.

Install and run Jenkins using Docker.

Complete the initial unlock and Administrator configuration.

Navigate and get familiar with the Jenkins web dashboard.

# Theory
Jenkins is an open-source automation server designed for Continuous Integration (CI) and Continuous Delivery (CD). Instead of developers manually building and testing code, Jenkins automatically monitors source control platforms (like Git). Whenever changes are pushed, Jenkins instantly triggers workflows to compile, test, and deploy the application, reducing human error.

Jenkins uses a web-based dashboard and supports thousands of plugins, allowing it to easily integrate with tools like Maven, Gradle, and Docker.

# Procedure
Step 1: Download and run the official Jenkins image:

docker run jenkins/jenkins:latest

Step 2 & 3: Verify running containers using docker ps, or list all containers (including stopped ones) using docker ps -a.

Step 4: Run a Jenkins container in the background (detached mode) with a custom sleep command:

docker run -d jenkins/jenkins sleep 200

Step 5 & 6: View container details, including network configurations like the IP address, using:

docker inspect <container_id>

Step 7: Launch Jenkins properly by mapping the terminal's port 8080 to the container's port 8080:

docker run -p 8080:8080 jenkins/jenkins:latest

Step 8: Open http://localhost:8080 in your web browser. Copy the initial setup administrator password printed in the terminal and paste it into the browser to unlock Jenkins.
